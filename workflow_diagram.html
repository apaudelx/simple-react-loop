Time Agent: request workflow

One question, “what time is it in Paris?”, traced end to end through the local ReAct loop (local_agent.py). The model never calls an API itself. It emits a JSON tool call; Python runs the function and feeds the result back, round after round, until the model answers in plain text.

What the model sees each round

messages[] is the agent's only memory. Every round resends the whole list, so it grows with each tool call. The next question appends to the same list, which is why the web UI has a Reset button: the 8192-token context fills up quickly.

local_agent.py / app.py Hand-written TOOL_SCHEMAS and a hand-written loop over an OpenAI-compatible endpoint (llama-server, LM Studio, Ollama…). app.py is a Flask wrapper around the same ask().
trace_agent.py Runs the same loop for one query and prints everything shown above: the model's reasoning, raw tool-call JSON, the real HTTP GETs, and token counts per round.
agent.py (Claude) @beta_tool generates schemas from the functions' docstrings, and the SDK's tool_runner runs this entire loop internally. It uses the same time_tools.py and a different provider.
